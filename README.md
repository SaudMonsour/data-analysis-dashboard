# لوحة تحليل البيانات

تطبيق تفاعلي لاستكشاف البيانات وتنظيفها وعرض الإحصاءات والرسوم باستخدام Streamlit.

[فتح التطبيق](https://saudmonsour-data-analysis-dashboard-app-uu96ud.streamlit.app/)

## الوظائف
- رفع ملفات CSV وExcel وتحليل محتواها.
- احتساب درجة لجودة البيانات من 0 إلى 100، اعتمادًا على القيم المفقودة والتكرار والقيم الشاذة واتساق البيانات.
- عرض ما تغيّر أثناء التنظيف، بما في ذلك إزالة التكرارات ومعالجة القيم المفقودة.
- رسوم توزيع ومبعثرات وخطوط وأعمدة ومخططات صندوقية تفاعلية.
- خريطة للارتباطات، وكشف القيم الشاذة بطريقة المدى الربيعي.
- اختبارات اعتدال التوزيع واختبار الفروق بين المتوسطات، مع تنبيهات عند صغر العينات أو عدم توازن المجموعات.

التفسيرات النصية داخل الإصدار الحالي موصوفة في التوثيق الأصلي بأنها باللغة الإنجليزية؛ تعريب ملف التعريف لا يغيّر لغة واجهة التطبيق.

## الملفات والتقنيات
نقطة الدخول هي `app.py`. تتوزع مهام الواجهة والبيانات والإحصاء والرسوم داخل `src/`، وتوجد بيانات تجريبية في `sample_data.csv`.

يعتمد المشروع على Python 3.8 فأحدث، ومكتبات pandas وNumPy وSciPy وPlotly، مع openpyxl لملفات Excel.

[المرجع التقني الإنجليزي الكامل](README.en.md).
